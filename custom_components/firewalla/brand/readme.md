#Note on device branding#

Custom integrations only allow for one icon / logo per integration.  
In order to simplify things for those of you with different models, 
I have included PNG files for the various Firewallas (except Orange, 
as there is currently no icon on their product branding page.

In order to brand your integration as you like it, simply rename the icon
of your choice to "icon.png" and you're done.
